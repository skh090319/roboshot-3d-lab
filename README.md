# RoboShot 3D Lab

고등학교 **역학과 에너지** 탐구 발표용 3D 농구 로봇 슈팅 시뮬레이터입니다. 포물선 운동의 해석식을 실제 시간에 적용하며, 발사 조건·궤적·에너지 그래프를 함께 비교할 수 있습니다. 로컬에서 실행되며 설치 후 외부 CDN이나 인터넷 API가 필요하지 않습니다.

[발표용 웹사이트](https://skh090319.github.io/roboshot-3d-lab/) · [GitHub 저장소](https://github.com/skh090319/roboshot-3d-lab)

화면 제목은 **물리학 수행 발표용**이며, 빨간 네온 궤적으로 공의 이동 경로를 표시합니다. 로봇의 준비 자세는 팔꿈치를 앞으로 굽혀 공을 받치는 형태이며 발사 시 팔을 펴는 Blender 애니메이션을 재생합니다. `main` 브랜치에 변경을 push하면 GitHub Actions가 테스트·빌드 후 GitHub Pages에 배포합니다.

## 설치와 실행

개발 환경은 Node.js 22.12 이상을 권장합니다. VS Code에서 프로젝트 폴더를 연 뒤 터미널에서 실행합니다.

```sh
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 여세요. 배포용 빌드와 오프라인 실행:

```sh
npm run build
npm start
```

`npm start`는 `http://127.0.0.1:4173`에서 빌드된 `dist/`를 제공합니다. 인터넷 서버가 아니라 본인 컴퓨터 내부의 정적 파일 서버입니다. `index.html`을 직접 더블클릭하는 대신 위 방법을 사용하세요. 터미널 실행은 `Ctrl+C`로 종료합니다.

Windows 배포본에서는 제공된 실행 파일을 이용하거나 아래 명령으로 실행할 수 있습니다. `runtime/node.exe`가 포함된 배포본은 별도의 Node.js 설치 없이 실행됩니다.

바탕화면의 **RoboShot 3D Lab** 바로가기 또는 프로젝트의 **RoboShot-실행.cmd**를 더블클릭하면 됩니다. 바탕화면 배포본은 휴대용 Node와 npm을 포함합니다. 일반 npm이 설치되어 있지 않으면 PowerShell에서 `npm` 대신 `.\npm.cmd`를 사용하세요. 실행에는 인터넷이 필요 없으며, 소스 개발용 의존성을 처음 설치하는 `npm install`에는 인터넷이 필요합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1
```

## 조작

- 슬라이더 또는 숫자 입력으로 발사 각도, 초기 속력, 발사 높이, 골대 거리, 질량, 재생 속도를 조절합니다.
- **SHOOT**: 현재 조건으로 슈팅합니다. **PAUSE / RESUME**: 일시정지·재개. **RESET**: 공과 시간을 초기 상태로 되돌립니다.
- **AUTO CALCULATE**: 현재 각도에서 림 중심 높이를 지나는 초기 속력을 계산합니다.
- **OPTIMIZE**: 주어진 거리와 높이 차이에서 필요한 초기 속력이 최소가 되는 각도와 속력을 계산합니다. 실제 농구의 최고 득점 확률 조건을 의미하지 않습니다.
- 마우스 드래그로 회전하고 휠로 확대·축소합니다. 전체·측면·로봇·골대 시점과 카메라 초기화 버튼을 지원합니다.
- 그래프 확대 버튼으로 발표용 큰 그래프를 확인합니다. 발표 모드는 제어 패널을 줄이고 장면과 핵심 물리 수치를 강조합니다.
- 저사양 기기에서는 그래픽 품질을 낮추세요. 픽셀 비율과 그림자 품질을 제한하며 그래프 객체는 재사용합니다.
- 오차 분석은 지정한 시드로 100회 가상 슈팅을 재현합니다. 결과는 **이 프로그램의 이상화된 모델에서 계산한 값이며 실제 토요타 CUE 로봇의 측정 결과가 아닙니다.**

## 적용한 물리

좌표는 **+X가 골대 방향, +Y가 높이, Z가 좌우**, 길이는 미터입니다. 중력가속도 `g = 9.8 m/s²`, 림 높이 `H = 3.05 m`, 공 반지름 `r = 0.12 m`, 림 안쪽 반지름 `R = 0.225 m`를 사용합니다. 입력 각도는 도 단위이며 계산 전에 라디안으로 변환합니다.

```text
x(t)  = v₀ cosθ · t
y(t)  = h + v₀ sinθ · t − ½gt²
vx(t) = v₀ cosθ
vy(t) = v₀ sinθ − gt
y(x)  = h + x tanθ − gx² / (2v₀² cos²θ)

최고점 시간: t_apex = v₀ sinθ / g
최고점 높이: y_apex = h + (v₀ sinθ)² / (2g)

자동 속력: v₀² = gd² / [2 cos²θ · (d tanθ + h − H)]
최소 속력 각도: θ_opt = 45° + ½ atan((H − h) / d)
                 ※ atan 결과를 도 단위로 변환

운동 에너지: Ek = ½m(vx² + vy²)
위치 에너지: Ep = mgy
역학적 에너지: Etotal = Ek + Ep
```

자동 속력 식의 분모가 0 이하이거나 입력이 유효하지 않으면 오류 이유를 표시합니다. 질량은 에너지에 영향을 주며 공기 저항이 없는 궤적에는 영향을 주지 않습니다. 재생 속도는 화면에서 시간이 흐르는 속도만 바꿉니다. 물리 상태는 누적 적분 대신 해석식으로 구하므로 프레임레이트가 궤적을 바꾸지 않습니다.

## 득점 판정과 한계

공 중심이 림 높이를 **하강하면서** 통과하는 정확한 시간을 계산합니다. 그 순간 수평면에서 공 중심과 림 중심 사이 거리가 `R − r = 0.105 m` 이하여야 성공입니다. 높이를 지나는 순간이 상승 중이거나 최고점이 부족하면 성공으로 처리하지 않습니다.

이 판정은 공과 림의 크기를 반영한 **이상화된 통과 판정**입니다. 실제 림·백보드·그물과의 충돌, 림 두께에 따른 비스듬한 진입 간섭, 공의 변형, 공기 저항, 회전·마그누스 효과를 재현하지 않습니다. 실패 오차는 하강 통과 순간의 수평 중심 오차이며 림 높이에 도달하지 않는 경우에는 해당 오차를 정의하지 않습니다. 공이 바닥에 닿으면 비행을 종료하며 튀어 오름은 모델링하지 않습니다.

위치 에너지는 코트 바닥을 기준으로 한 **공 중심 높이**로 계산합니다. 바닥 접촉 전까지 전체 역학적 에너지는 부동소수점 오차 범위에서 보존됩니다.

## 파일 구성과 모델

```text
src/physics.js         독립적인 물리 계산
src/scene.js           Three.js 렌더링·카메라·로봇 동작
src/models.js          절차적 모델 제작 및 대체 모델
src/charts.js          Chart.js 분석 그래프
public/models/         웹용 GLB 모델
scripts/               모델 내보내기·로컬 실행
tests/                 자동 물리 검증
dist/                  빌드 후 생성되는 오프라인 실행 파일
```

설치된 **Blender 5.2.2 LTS**를 공식 `mcp-for-blender 2.2.6` MCP 서버로 직접 조작해 모델을 만들었습니다. 원본은 `assets/RoboShot-3D-Lab.blend`, 제작 코드는 `scripts/build_blender_models.py`입니다. `public/models/robot.glb`, `court.glb`, `hoop.glb`를 Three.js GLTFLoader로 로드합니다. 어깨와 팔꿈치의 회전 4개 채널을 Blender 키프레임으로 내보냈으며, 물리적 공의 비행은 별도 해석식으로 제어합니다. 로봇은 선택한 발사 높이에 맞춰 시각적으로 비례 조절되며 농구공과 림 크기는 고정됩니다.

실제 GLB를 Three.js로 다시 읽어 림 높이 `3.049999952 m`, 내측 반지름 `0.224999982 m`, Y-up 방향, 미터 단위, 관절 움직임과 종료 후 반복 재생을 검증했습니다. `node scripts/verify-models.mjs`로 모델 검증을 다시 실행할 수 있습니다. GLB 3개의 합계 크기는 약 2.21 MB입니다. GLB 로딩이 불가능한 경우에만 절차적 Three.js 모델로 대체합니다.

현재 PC의 Codex에는 `blender` MCP가 등록되어 있습니다. 이 프로젝트 제작은 실제 MCP stdio 브리지로 호출했으며, 새 Codex 실행부터 기본 MCP 도구 목록에서도 사용할 수 있습니다. 실행용 웹 앱은 Blender나 MCP가 없어도 동작합니다.

사용 기술은 Vanilla JavaScript ES Modules, HTML5, CSS3, Three.js, OrbitControls, Chart.js, Vite입니다. 참고 문서: [Three.js](https://threejs.org/docs/), [Chart.js](https://www.chartjs.org/docs/latest/), [Vite](https://vite.dev/guide/).
